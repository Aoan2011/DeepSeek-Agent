# 2026-11-15

## chat-agent 液态玻璃 / 模糊 / 参数改造

- 新增 `src/components/glass/liquidGlass.ts` + `useLiquidGlass.ts`：把 liquid-glass-web 的折射算法（canvas 位移贴图 + SVG feDisplacementMap + backdrop-filter url()）搬成模块。默认参数 `ref .45 / edge .6 / rad .6 / tint .11 / blur 1`，非 Chromium 退化为 `data-glass='blur'` 毛玻璃。
- 侧边栏（Sider）与输入框（ChatInput）都挂 `useLiquidGlass`；`useLiquidGlass(params?: Partial<GlassParams>)` 支持按场景微调（合并到默认值）。
- **经验**：给输入框加大 blur/tint（试过 blur 11 / tint .15）会变成普通毛玻璃，用户明确拒绝，要求回到 `blur 1 / tint .11` 的清透折射版。以后不要擅自加雾。
- `ProgressiveBlur` 组件（6 层 backdrop-filter 叠蒙版）实现顶部与输入框下方的渐进式模糊。
- `ContextRing`：上下文占用圆环，空状态显示 `–` 而不是 0；数据来自 `services/chat/contextUsage.ts`。
- 设置新增「Agent 运行时」分组：启用工具调用、工具执行权限（每次确认 / 完全访问 → `toolApproval`）、最大步数开关（`maxStepsEnabled` + `maxToolRounds`）、采样参数（temperature / topP，null = 不下发）、演示模式。
- 采样滑杆：`--fill` 渐变填充表示已选段，`data-inherit` 表示跟随服务端默认（滑块停在默认值位置）。
- 深度思考档位改为文字（关闭/轻微/标准/深度/极致），去掉数字角标；工具卡片图标去掉外部遮罩方块。
- 桌面端沙箱新增 `allowed_paths`（默认 `~/.skills`，可用 `AGENTDESK_SKILLS` 覆盖），`Sandbox(root, allowed)` 放行该目录；`desk_info`/工具描述同步说明。
- 实时状态条速度改为**瞬时速度**：`LiveRun.samples` 存 (t, tokens) 采样点（保留 4s / 最多 240 个），`readLiveMetrics` 用最近 1.2s 窗口做差分；`active` 时给瞬时值，结束后给整轮平均（`readLiveMetrics` 里的 `averageTps`）。一轮开始时清空 samples，避免估算清零造成负跳变。
  - 用户明确要求：tok/s 必须是瞬时，不是累计平均。别改回 `outputTokens / streamSeconds`。
- 新增右侧「问题导航」（`components/messages/QuestionNav.tsx`）：消息区右缘一列刻度对应每条用户提问，悬停展开问题列表，点击平滑滚到该条。
  - `MessageList` 外面包了一层 `.root`（position: relative）用来定位导航，`.container` 仍是滚动容器。
  - `UserMessage` 根节点加了 `data-message-id`，导航靠它 querySelector 定位与测距；`ACTIVE_OFFSET=96` 判定当前提问，`JUMP_OFFSET=72` 留出标题栏高度。
  - 跳转必须把 `stickyRef.current = false`，否则流式内容会把视线拽回底部。

## 常用命令

- 开发：`npx rspack serve -c rspack.config.ts`（localhost:8090）
- 校验：`pnpm type` / `pnpm lint` / `NODE_ENV=production npx rspack build -c rspack.config.ts`
- 生产构建**必须前台执行**：放后台跑会以 `GenericFailure` 结束，且会先把 `dist/` 清空导致没有 index.html。
